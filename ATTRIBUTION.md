# Attribution

This package bundles data from the SkyWater SKY130 open-source PDK ecosystem.

- SkyWater SKY130 PDK: https://github.com/google/skywater-pdk (Apache-2.0)
- open_pdks: https://github.com/RTimothyEdwards/open_pdks (Apache-2.0)
- OpenROAD-flow-scripts SKY130 HD platform:
  https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts (Apache-2.0)

The package's `LICENSE` is Apache-2.0. Directory-level details are recorded in:

- `layout/ATTRIBUTION.md` — PCell definitions and the device index.
- `implementation/ATTRIBUTION.md` — standard-cell, stack, RCX, and script data.

The ngspice model tree under `simulation/ngspice` retains the upstream file
headers and license notices.
